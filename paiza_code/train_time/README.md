実業家の paiza さんは、A 市を 1 周する鉄道を作ることを計画しています。全ての電車は起点駅を出発し、時計回りに 1 周します。なるべく安い値段で鉄道を作りたいので、 paiza さんは N 本の列車を購入しようとしています。それぞれの列車には性能差があり、整備の事情を考慮すると、時刻 L_i (1 ≦ i ≦ N) に起点駅を出発し、時刻 R_i (1 ≦ i ≦ N) に起点駅に戻ってくるようにしなければなりません。

困ったことに、計画している鉄道は途中で他の列車を追い越すことが出来ません。すなわち、L_a ≦ L_b かつ R_b ≦ R_a (1 ≦ a, b ≦ N, a ≠ b) となるような 2 つの列車は同時に運行することができません。

楽観的な paiza さんは、全ての列車が運行できるかどうかが気になっています。

N 本の列車全てが運行できる場合 "Yes" を、そうでない場合は "No" を出力するプログラムを作成してください。


入力は次のフォーマットで与えられます。
N
L_1 R_1
L_2 R_2
...
L_N R_N

・1 行目に、paiza さんが購入しようとしている列車の数を表す整数 N が与えられます。
・続く N 行のうち、i (1 ≦ i ≦ N) 行目は、i 番目の列車の出発時刻を表す整数 L_i と、到着時刻を表す整数 R_i が与えられます。
・入力は合計で N+1 行となり、末尾に改行が 1 つ入ります。

文字列は標準入力から渡されます。


N 本の列車全てが運行できる場合 "Yes" を、そうでない場合は "No" を出力するプログラムを作成してください。

末尾に改行を入れ、余計な文字、空行を含まないでください。
条件
すべてのテストケースにおいて、以下の条件をみたします。
・1 ≦ N ≦ 100,000
・- 0 ≦ L_i < R_i ≦ 100,000,000 (1 ≦ i ≦ N)
