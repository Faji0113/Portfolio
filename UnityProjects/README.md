O.  参考書内の仕様
・コインドーザーのクッキーバージョン。
・画面をタップするとクッキーが射出される。
・クッキーが落ちるとエフェクトとともに消え、クッキーの所持数が3増える。
・クッキーの所持数がある数を以下になったら既定の秒数経過後1増やす。
・一度に連続して射出できるクッキーは5個まで。既定の秒数で回復する。

1. 自分で追加実装した機能
・タイトルシーン->時間計測スタート、ゲーム開始->(クッキーの所持枚数が100枚以上になったら)時間計測停止、shootの入力受付停止、クリアパネルを表示。->(パネル内のボタンを押す)タイトルに戻る

・手持ちのクッキーがない場合や一度の射出上限を超えた後も画面をタップすると赤文字で警告が入るようにした。

・クリアパネルにはクッキー所持枚数が100枚になるまでにかかった時間が書かれた文が載るようにした。
