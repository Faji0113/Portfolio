考察
1. 時間計算量
 展開ノード数は時間計算量に直結しており、表 3 の右に行くほど小さくなっていることから, 時間計算量は IDS>A*_h0>A*_h1>A*_h2 と読み取れる。また、分散も同様に右にいくほど小さくなっていることから、表の右の探索方法ほど盤面に依らず時間計算量が安定しているといえる。IDS と A*_h0(幅優先探索)の計算量は理論上 O(bd)(b:分岐数, d:ゴールまでの深さ)で表されるが, IDS は d=0, d<=1, d<=2, ..と繰り返し探索を行うため, IDS の方が計算量が多くなったと考えられる。また,A*_h1 と A*_h2 に関して, より優位なヒューリスティック関数を用いている A*_h2 の方が確かに計算量が少ない。
2. 空間計算量
 最大 Open サイズは空間計算量に直結しており、表 3 の平均と分散から IDS が最も小さく安定していることがわかる。これは深さ制限によって枝刈りしているからだと考えられる。A*どうしでは h2, h1, h0 の順に空間計算量が少なく、初期盤面の依存性も低い。したがって、ヒューリスティック関数が優位であるほど空間計算量は小さいことがわかる。
3. 探索コスト
 探索にかかるコストの合計の目安として実行時間を採用した。結果、A*_h2, A*_h1, A*_h0,IDS の順に探索コストが小さいことが読み取れた。したがって、この順に探索は効率的であると考える。
4. 完全性および最適性
 4 種類の探索方法はいずれも完全性と最適性を持っていることが確認できた。しかし、実行結果の一例では, 4種類とも 14 通りで解いているものの、タイルの動かし方のパターンが異なるものがあり、IDS と A*h_0 の出力した解答と、A*h_1と A*h_2 の出力した解答は異なっている。したがって、最適解が複数ある場合は探索方法によってどの解き方をするかが異なることがわかる。
